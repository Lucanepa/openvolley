# User Guide

## Introduction
Openvolley eScoresheet allows you to digitally score volleyball matches, automatically tracking rotations, substitutions, and creating an official scoresheet.

## Basic Workflow

1.  **Create a Match:**
    -   On the home screen, click "New Match".
    -   Enter match details (teams, location, date, officials).
2.  **Enter Rosters:**
    -   Add players for both teams manually or import them.
    -   Designate liberos and captains.
3.  **Start the Match:**
    -   Perform the coin toss.
    -   Set starting lineups for the first set.
4.  **Scoring:**
    -   Click on the team side that won the rally to award a point.
    -   Use the **Substitution** button to record substitutions.
    -   Use the **Timeout** button to record timeouts.
    -   Sanctions (Cards) can be recorded via the sanctions menu.
5.  **End of Set:**
    -   Confirm the set score.
    -   Switch sides automatically.
    -   Set lineups for the next set.
6.  **Finish Match:**
    -   Once the match is won, finalize the match.
    -   Signatures can be captured digitally.
7.  **Export:**
    -   Generate and download the PDF scoresheet.

## Troubleshooting Sync
If data is not appearing on the live server:
-   Check the internet connection indicator in the app.
-   Ensure you are logged in if authentication is required.

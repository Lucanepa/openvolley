# Welcome to the Openvolley eScoresheet Wiki

**Openvolley eScoresheet** is a powerful, offline-first volleyball match scoring application designed for referees, scorers, and data volleys. It provides a seamless experience for managing matches, tracking scores, and generating official scoresheets.

## Key Features

- **Offline-First:** Works completely offline using local database storage (Dexie.js), syncing when a connection is available.
- **Cross-Platform:** Available as a Web App, Desktop App (Windows, macOS, Linux via Electron), and Mobile App (Android/iOS via Capacitor).
- **Official Scoresheets:** Generates PDF scoresheets compliant with standard volleyball regulations.
- **Real-time Sync:** Supports synchronization with a backend server (Supabase) for live scoring and data persistence.
- **Multi-Role Support:** Dedicated interfaces for Scorers, Referees, and Bench/Coaches.

Install with one command

Adds the signed APT repository (it checks the key fingerprint below first) and installs the app. Running it again is harmless.

curl -fsSL https://get.openvolley.app/install.sh | sudo sh

Read it first if you like: install.sh

From then on

sudo apt install @DEB_PACKAGE@
sudo apt update && sudo apt upgrade

Start it from the app menu (OpenVolley eScoresheet) or with @DEB_PACKAGE@. Headless relay for the tablets only: @DEB_PACKAGE@ --server-only.

Or by hand (same result)

curl -fsSL https://get.openvolley.app/apt/openvolley.gpg | sudo tee /usr/share/keyrings/openvolley.gpg >/dev/null
echo 'deb [arch=amd64 signed-by=/usr/share/keyrings/openvolley.gpg] https://get.openvolley.app/apt stable main' | sudo tee /etc/apt/sources.list.d/openvolley.list
sudo apt update && sudo apt install @DEB_PACKAGE@

Check the key before trusting it: gpg --show-keys /usr/share/keyrings/openvolley.gpg must show the fingerprint below. Installed the .deb from GitHub before (package openvolley-e-scoresheet)? sudo apt install @DEB_PACKAGE@ replaces it.

Windows @DESKTOP_VERSION@ · 64-bit

Download and run the installer from the GitHub release. Windows may show a SmartScreen notice for a new download: More info → Run anyway.

It installs for all users and asks once for an administrator: that lets the tablets on the local network through Windows Firewall. An earlier version installed by the same Windows account is replaced; matches and backups stay. Typed an administrator's password into a standard account? Then the earlier version stays as well: remove it in Settings › Apps (its matches stay).

Automatic updates

Android

F-Droid keeps the app up to date: on Android 12 and newer it installs updates by itself, with no tap, while the tablet is idle (never while the scoreboard keeps the screen on). Android 7 to 11 shows one Update tap. On a scorer tablet use the F-Droid client 2.0 or newer, and in F-Droid set Settings → app auto-updates → Only on Wi-Fi. Installed from f-droid.org? It builds each version some days after it appears here; add this repository in F-Droid to get it right away.

Installed the APK from the browser? Open OpenVolley in F-Droid once and tap Update: from then on F-Droid updates it. Without F-Droid the app can tell you about a new version instead, if you say yes when it asks (about once a day it reads the version list on this site, never during a match; nothing else is sent). It never installs anything itself.

Windows and Linux

From version 2.2.0 the desktop app updates itself: it downloads the update in the background and installs it when you quit OpenVolley, never during a match. Windows asks once for an administrator per update. Linux installed with the command above updates in the background and runs the new version from the next start. Version 2.1.x and older: install 2.2.0 once by hand (Linux: sudo apt update && sudo apt upgrade).
